# Bundled salary PDF fonts

These SIL Open Font License 1.1 fonts are embedded so PDF statements render
correctly while the app is offline:

- `NotoSans-Regular.ttf` — Noto Sans, from
  https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
- `NotoSansBengali-Regular.ttf` — Noto Sans Bengali, from
  https://github.com/notofonts/noto-sans-bengali/tree/main/unhinted/ttf
- `NotoSansDevanagari-Regular.ttf` — Noto Sans Devanagari, from
  https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSansDevanagari

License text: https://openfontlicense.org/ . Noto font licenses and copyright
notices are maintained by the upstream projects.
